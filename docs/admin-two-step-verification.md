# Turning On Two-Step Verification (for each administrator)

Each administrator does this once, signed in as themselves. It takes about five minutes.
Nobody else can do it for you, and nobody should ever ask for your codes.

## What you need
- Your admin email and password for tramainecrawford.com.
- A phone with an authenticator app: Google Authenticator, Microsoft Authenticator,
  1Password, Authy, or similar (free).

## Steps
1. Go to **tramainecrawford.com/login** and sign in as usual.
2. In the admin panel, open **Security & activity** (left menu, under *Insights & security*).
3. Under **Two-step verification**, select **Turn on two-step verification**.
4. Open your authenticator app, choose **Add account / Scan QR code**, and scan the code on screen.
   If you can't scan it, choose *Enter a setup key* and type the key shown under the QR code.
5. The app now shows a 6-digit code for "TLC". Type it into **Code from the app** and select **Confirm**.
6. You'll see "Two-step verification is on."

From now on, each time you sign in you'll be asked for the current 6-digit code from the app.

## Good practice
- Add the account to a second device or a password manager that syncs (for example 1Password),
  so losing your phone doesn't lock you out.
- If one administrator loses access, the other administrator can still sign in. Contact your
  web administrator to reset the lost authenticator; never share codes by email or text.
- Codes change every 30 seconds. If one is rejected, wait for the next code and try again.

- **Pathways & Programs:** review the three pathway descriptions. Enrollment is closed and no

- **Security → Email delivery:** shows every email the site has sent, and whether it succeeded.
